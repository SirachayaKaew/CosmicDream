## About

**CosmicDream** is an independent Minecraft modification for Minecraft Forge 1.20.1, inspired by the world, atmosphere, and concepts of **Touhou Project**.

The project aims to introduce a mysterious dimension known as **Dreamworld**, where players can explore an unusual environment beyond the boundaries of the ordinary Minecraft world.

This project is currently in its **Demo stage**. Its primary purpose is to introduce the core concepts, experiment with gameplay systems, and establish the foundation for future development.

CosmicDream is still actively being developed, and many planned features have not yet been implemented.

## Dreamworld

**Dreamworld** is a mysterious dimension that serves as the central setting of CosmicDream.

The dimension is designed around an unusual environment featuring:

- A mysterious atmosphere and a moonlit sky.
- An endless-looking grid stretching into the distance.
- Floating platforms and islands.
- An unusual environment surrounded by an endless void.
- Potential hidden locations, structures, and life forms waiting to be discovered.

The world is intended to feel unfamiliar, mysterious, and different from the dimensions found in vanilla Minecraft.

## Features

The following features describe the current development direction. Availability may vary depending on the Demo build.

### Dimension System

- A custom dimension called Dreamworld.
- A unique environment separate from the Overworld.
- A custom void environment.
- An experimental grid-based world structure.

### Entering Dreamworld

The planned dimension access system includes two methods:

- **Dream Key:** An item intended to allow players to enter and leave Dreamworld.
- **Dream Bed:** A special bed intended to provide an alternative way to enter Dreamworld. (Future)

Both methods are designed around nighttime conditions.

### Teleportation System

- Custom dimension travel.
- Transition effects between dimensions.
- Saved player positions to support returning to previous locations.

### Future Content

- Floating islands and unique structures.
- Custom creatures and life forms.
- Boss encounters.
- Additional items and gameplay mechanics.
- More environmental features and exploration content.

## Installation

1. Install Minecraft Forge for Minecraft 1.20.1.
2. Download the appropriate CosmicDream release.
3. Place the downloaded `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft using the Forge profile.
5. Check the Mods menu to confirm that CosmicDream is installed.

**Note:** This project is currently in Demo development. Bugs, incomplete features, and unexpected behavior may occur.
**Note2:** If you download shaders go to your shader settings and turn OFF clouds
